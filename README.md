# Movie Reviewer - CineScope 🎬

A stunning, feature-rich movie discovery and review platform. Search for any movie and instantly get comprehensive details including reviews, budget, box office collection, streaming availability, cast & crew, trailers, and more.

![CineScope](https://img.shields.io/badge/CineScope-Movie%20Reviewer-7c5cfc?style=for-the-badge)

## ✨ Features

- **🔍 Smart Search** — Real-time autocomplete search with movie suggestions
- **📊 Box Office & Financials** — Budget, revenue, profit/loss, and ROI
- **📺 Where to Watch** — Streaming, rent, and buy availability (powered by JustWatch)
- **📝 User Reviews** — Read community reviews with ratings
- **🎭 Cast & Crew** — Full cast list with character names, directors, writers, producers
- **🎥 Trailers & Videos** — Watch trailers directly from YouTube
- **🎞️ Similar Movies** — Discover related films
- **🏢 Production Info** — Production companies and origin countries
- **🔥 Trending / Top Rated / Upcoming** — Browse curated lists
- **📱 Fully Responsive** — Works beautifully on desktop, tablet, and mobile

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/movie-reviewer.git
   cd movie-reviewer
   ```

2. **Get a free TMDB API Key**
   - Go to [themoviedb.org](https://www.themoviedb.org/signup) and create a free account
   - Navigate to Settings → API → Create → Developer
   - Copy your API Key (v3 auth)

3. **Open `index.html` in your browser**
   - No build step required! Just open the file directly
   - Or use a local server: `npx serve .`

4. **Enter your API key** when prompted on first launch
